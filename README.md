# PhonePe_Transactions_Analysis_Dashboard
### 📌 Project Title
PhonePe Payment Insights Dashboard | Power BI Data Analytics Project

### 📝 Short Description

This project is an interactive Power BI dashboard built using PhonePe transaction data to analyze payment trends, user behavior, transaction success rates, and service-wise payment distribution. The dashboard enables stakeholders to monitor key business metrics, identify customer segments, and make data-driven decisions through dynamic visualizations.

### 🛠️ Tech Stack
- Power BI – Dashboard Development & Visualization
- Microsoft Excel – Data Source & Cleaning
- Power Query – Data Transformation (ETL)
- DAX (Data Analysis Expressions) – Measures & KPIs
- Data Visualization – Interactive Charts, Cards, and Filters

### 📂 Data Source

The dashboard uses a Microsoft Excel (.xlsx) dataset containing PhonePe payment transaction records.
(Dataset is included in this repository)

### ✨ Features & Highlights
#### 📈 Executive Dashboard
- Displays Total Transactions
- Total Transaction Value
- Unique Users
- Transaction Success Rate
#### 📊 Trend Analysis
- Monthly Transaction Trend
- Monthly Revenue Trend
- Growth Analysis
#### 👥 Customer Insights
- Age-wise User Contribution
- Top 5 Users by Transaction Value
- Weekday vs Weekend Usage Pattern
#### 💳 Service Analysis
- Loan Transactions
- Insurance Payments
- Money Transfers
- Recharge Bills
#### 🎯 Interactive Filters
- Month Filter
- Payment Status Filter
- Dynamic Visual Updates
### 💼 Example Business Problem

PhonePe wants to understand:

- Which customer segments contribute the highest transaction volume?
- How transaction values change throughout the year.
- Which services generate maximum revenue.
- Whether weekdays or weekends experience higher payment activity.
- Overall payment success performance.

This dashboard provides a centralized solution for answering these business questions through interactive visual analytics.

❓ Key Questions Answered
- Which month records the highest transaction volume?
- What is the total transaction value?
- What is the payment success rate?
- Which age group contributes the most transactions?
- Which PhonePe services generate the highest transaction value?
- Who are the top users based on transaction value?
- Are more transactions made on weekdays or weekends?
- How does payment status (Successful, Failed, Pending) affect overall performance?

### 📈 Business Impact

This dashboard helps stakeholders to:

- Monitor business performance in real time
- Identify high-value customer segments
- Track payment success rates
- Improve service-level decision making
- Understand seasonal payment trends
- Optimize marketing campaigns for target age groups
- Support strategic business decisions using data-driven insights
